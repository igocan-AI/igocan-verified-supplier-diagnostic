## 项目说明

本项目是阿里国际站"金品诚企"商家的**专属权益深度诊断工具**，以 AI Skill 形式实现一键店铺体检。

核心能力覆盖：

- **金品认证完整度**：检测二次补验、全景看厂、证书有效期
- **AI知识库丰富度**：评估公司/商品/沟通技巧三大知识库填充率
- **RFQ专属特权消耗**：监测畅行/置顶报价权月度使用进度
- **AI算力(i豆)利用率**：诊断9000 i豆/月消耗比例及子账号分配
- **买家资产沉淀**：L0-L4分层启用与高价值买家跟进策略

诊断输出为结构化《金品诚企专属权益体检报告》，含健康度评分、红灯警告、绿灯优势及落地优化Action。
